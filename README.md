# منصة فيا للتسويق الرقمي بالذكاء الاصطناعي (VIA AI Platform)

منصة تسويق رقمي متقدمة ومستقلة بالكامل مبنية بتقنيات React + Vite + TailwindCSS، مع قاعدة بيانات مضمنة معزولة (PGlite PostgreSQL) وواجهة برمجة تطبيقات (Node REST API).

## المميزات الرئيسية
- ⚡ **أداة مقياس الأداء الشامل (Performance Meter)**: حاسبة تفاعلية حية لحساب الهدر الإعلاني ومعدل العائد (ROAS) ونمو الأرباح بالذكاء الاصطناعي.
- 🎯 **كتالوج الخدمات**: 6 خدمات تسويقية متكاملة (سيو الذكاء الاصطناعي، الحملات الممولة، السوشيال ميديا، المتاجر الإلكترونية، وغيرها).
- 📊 **دراسات الحالة والنتائج**: قطاعات حقيقية وموثقة (تمور، رماية، عطور).
- 📩 **محرك إدارة العملاء المحتملين (Leads Engine)**: استيعاب وحفظ بيانات الاستشارات في قاعدة بيانات مستقلة تماماً.
- 💬 **زر واتساب عائم ودعم متكامل لكافة الشاشات (Responsive)**.

## متطلبات التشغيل
- Node.js >= 18.0.0

## أوامر التشغيل
```bash
# تثبيت الحزم
npm install

# تشغيل السيرفر وقاعدة البيانات والواجهة معاً:
node start.cjs

# أو تشغيل الواجهة فقط:
npm run dev
```
